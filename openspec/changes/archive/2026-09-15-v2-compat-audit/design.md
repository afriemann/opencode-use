## Design Exemption

This change adds a documentation artifact (`docs/v2-compat-audit.md`) recording
research findings about opencode V2 plugin API compatibility. No `architect`
or `ui-designer` commission was required — all four design-skip criteria hold:

1. Pure documentation addition with no architectural dimension.
2. No function, module, or component is created or modified.
3. No infrastructure or configuration changes.
4. No new dependencies.

See `proposal.md` for the full rationale and `tasks.md` for the audit's
concrete research and writing steps.
